# PVQC 電機電子專業英文測驗挑戰系統 (793 題庫)

> **系統開發設計：劉建良@2026 免費軟體** ｜ 版本：`v2.3.4`

專為 **PVQC (Professional Vocabulary Quotient Credential) 專業英文詞彙能力國際認證 - 電機電子類** 設計的線上互動測驗與訓練系統。提供離線純前端架構、趣味音效與多樣化測驗模式，免費學習分享。

* 🌐 **線上測驗網址**：https://alanmaxliu.github.io/PVQC_Test/

---

## 🎮 測驗與遊戲模式簡介

1. **📝 PVQC 經典單選**：
   * 標準四選一測驗，依據英文單字選出正確中文釋義，擬真官方認證考驗。
2. **🔀 打散代號配對**：
   * 左右雙欄獨立滑動對照，支援繁體中文首字筆畫排序、關鍵字即時搜尋與只顯示未配對選項。
3. **🧩 卡片速配消消樂**：
   * 點選配對的英文單字與中文釋義進行消除，考驗快速聯想能力。
4. **⌨️ 拼寫實戰挑戰**：
   * 依據中文提示鍵入正確英文單字，強化專業拼寫能力。

---

## ⚙️ 功能特色

* **自訂題庫範圍**：支援任意序號區間（1 ~ 793）與自訂抽考題數（隨機抽考或全考打散）。
* **標準語音發音**：支援英文單字語音朗讀（Web Speech API 與真人語音）。
* **錯題特訓模式**：測驗結算後可一鍵「僅重測此回錯題」，精準強化記憶。
* **電玩趣味音效**：內建互動音效反饋，支援一鍵開啟或靜音。
* **行動端極致優化**：針對手機直立螢幕進行流暢響應式排版。
